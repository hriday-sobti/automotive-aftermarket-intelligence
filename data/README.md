# Automotive Aftermarket Intelligence Data Architecture

This directory holds the raw synthetic data, intermediate validated frames, and processed star-schema data tables.

- `raw/`: Unprocessed synthetic data directly generated by `src/data_generation/`.
- `interim/`: Data passing validation checks, intermediate feature tables, and reconciliation rejects.
- `processed/`: Production-ready dimensional star-schema CSVs and SQLite analytical database `aftermarket.db`.

*Note: All data in this directory is project-generated synthetic data for modeling and commercial decision analytics.*
